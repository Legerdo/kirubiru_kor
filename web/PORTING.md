# 이식 근거와 확인 범위

## 보존 기준

원본 `run.exe` SHA-256: `754034ee26fec593859607d2c2465d6a532589aabf15126d7b7f4bca28bdaf7a`.

`research/original-manifest.json`은 원본 실행 파일과 data/image/sound/save의 100개 파일을 기록합니다. 원본 99개 리소스는 `public/assets/`에 바이트 그대로 보존합니다. `tools/prepare-assets.py`는 이 내장 복사본의 해시를 검사하고 원본 텍스처 ID 매핑을 생성합니다. 상위 원본 폴더를 읽지 않습니다. 이미지를 새로 생성하거나 캐릭터/배경을 대체하지 않았습니다.

분석은 REA와 IDA의 격리된 분석 DB 및 `research/original-analysis.exe` 복사본을 사용했습니다. 호환성 문제로 원본 실행을 금지한 사용자 지시 이후 원본 실행/화면 모드 변경은 하지 않았습니다. 시작 단계의 실행 시도는 조작 가능한 창을 얻지 못했고, 이후 작업은 정적 분석과 웹 산출물 검증으로 한정했습니다.

초기 REA 근거: `ev_321aa0d0f08b4b43c8db35ca2e8056abad518d9eee164dfca3321bd514a24641`(개요), `ev_13a84ed2ade8703b5873e5b2e80d9b7bb4fff2550fabeb1ff15dc9dc02d237dc`(리소스/입력 초기화), `ev_8c9d8014e15e3253cf749b0cc784ac692d1a682b22472a8b65da5eb7938a711f`(메시지 루프). 디컴파일 결과는 원본 소스가 아니며 추론된 타입/함수 경계에는 한계가 있습니다.

## 확인된 결과와 미해결 항목

- 중앙 계속하기 버튼은 기존 `setPause(false)`를 호출하고 게임에 포커스를 복원합니다. 일시정지 중 Tab과 해당 버튼의 Enter/Space는 기본 버튼 동작으로 전달합니다. `volume-qa.mjs`에서 클릭·터치·Tab/Enter/Space 재개, 음악 재개와 게임 프레임 진행을 검증했으며, `layout-qa.mjs`에서 12개 화면 크기 모두 버튼이 화면에 들어오고 실제 클릭·터치로 재개됨을 확인했습니다.
- 화면 높이는 `100dvh`로 제한하고 상·하단 UI를 뺀 남은 영역에 Phaser FIT 캔버스를 배치합니다. 조작법은 게임 밖의 상시 영역에 표시하며 화면 폭/높이에 따라 오른쪽 한 열·두 열 또는 하단 안내줄로 바뀝니다. 저장 패널은 독립된 펼침 영역입니다. `node tools/layout-qa.mjs`에서 12개 화면 크기의 패널 열림/닫힘 24개 상태, 창 회전/리사이즈, 휠 입력, 조작법 9개와 일시정지 문구를 검사했습니다. 페이지 스크롤·화면 밖 버튼·패널 내부 스크롤·게임/조작법 겹침·브라우저 오류가 없었습니다. Chromium 기준이며 결과는 `test-results/layout-report.json`과 PNG입니다.
- 볼륨 단축키 −/+ 및 숫자 키패드는 5%씩 조절하며 M은 기존 소리 버튼과 같은 경로로 음소거를 전환합니다. `volume-qa.mjs`에서 0/100% 제한, 키패드, 버튼 상태 동기화, 일시정지 중 M 전환과 무음 유지, 중앙 일시정지 표시/재개 시 숨김을 검증했습니다.
- 일시정지는 공통 출력 gain 0, TinySynth 스케줄러 정지, AudioContext suspend를 함께 적용합니다. TinySynth `send()`의 자동 resume로 음악이 다시 켜지는 경로를 차단하며, 스케줄·예약 음표·오디오 시간을 보존해 같은 위치에서 재개합니다. `volume-qa.mjs`는 700ms 동안 오디오 시간/음악 tick 불변, 정지 중 볼륨·소리 버튼 조작 후에도 suspend 유지, 재개 후 음악 위치와 설정 볼륨 복원을 검증합니다.
- `npm test`: 12개 통과. 원본 메뉴로 3개 모드 진입, 세 위치 이동, 점프의 원본 준비 동작, 공중 방어, 새 플레이의 세이브/리플레이 기록과 재생 점수 일치, 가져오기 경로/범위/길이, 칼/점수 투명색과 유색 디테일 보존, replay11 착지와 최종 기록 회귀 검증.
- BMP 투명색: `icon.bmp`의 배경 5,000픽셀은 RGB `(248,8,248)`, `score.bmp`의 숫자 경계 383픽셀은 `(254,2,254)`입니다. 팔레트 근사 전에 자홍색 키 `(255,0,255)`의 각 채널 오차 8 이내를 투명 인덱스로 정규화합니다. 전체 60개 텍스처 조사에서 정확한 키 외에 추가로 처리되는 색은 이 두 색뿐이며, 원본 파일은 변경하지 않습니다.

- 브라우저 검증은 실제 Chromium 키보드와 터치 입력, 일시정지, 제2막/무제한 선택, WAV/MIDI 시작, localStorage 쓰기, 데스크톱/390px 화면 스크린샷을 대상으로 합니다. 결과는 `test-results/browser-report.json` 및 PNG입니다.

## replay11 원인과 수정 근거

- **게임 로직 복원 오류:** `sub_402EE0`의 x87 비교가 디컴파일 결과에서 미정의 지역 변수 `v4/v5`로 남아 있었습니다. 원본 `0x402F0D`는 y와 304.0을 비교하고 `0x402F18 test ah,41h; jnz`로 이 값 이하/비정렬일 때 좌표를 사용하며, 초과하면 float y와 정수 y를 304로 제한합니다. 원본 명령어는 `research/0x402ee0.asm`에 보존했습니다. `tools/lift.py`는 해당 비교를 `!(v2 > 304.0)`으로 명시적으로 복원하며 예상 원문이 바뀌면 빌드를 거부합니다.
- 수정 전 프레임 9,933에서 연출 중 y=317.900177로 지면을 통과했고, 이후 y가 약 508,965까지 증가했습니다. 후반 전투가 어긋나 프레임 16,038 / stage 6 / 11,043,889점에서 조기 종료했습니다. `tests/replay-parity.test.mjs`의 착지와 점수 검사가 수정 전 모두 실패하는 것을 확인했습니다.
- 수정 후 제2막 stage 9까지 진행하며 프레임 26,891에 **32,589,689점 / 원본 저장 최대 콤보 75**로 끝납니다. 리플레이와 점수표 파일은 바이트 그대로이며 점수/입력 보정은 없습니다.
- **검사기 정의도 수정:** 종료 순간 진행 중 콤보 130과 원본 저장 최대 필드 75는 별도입니다. 원본 `sub_40FF80`, 특히 `0x410037–0x410046`은 점수와 `dword_41F6A0`를 직접 저장합니다(`research/0x40ff80.asm`). `max(currentCombo,maxCombo)`로 저장 값을 대신하는 것은 원본 규칙이 아니므로 검증에서 `final.maxCombo`와 비교합니다. 회귀 검사는 저장 최대 75와 진행 중 콤보 130을 각각 고정해 두 필드를 혼동하지 못하게 합니다.

## 상위 원본 없는 재빌드

`research/initial-image.bin`과 `research/reconstruction-inputs.json`에 초기 메모리 이미지 579,328바이트와 두 코드 상수 테이블, 출처 EXE SHA-256 및 입력별 SHA-256을 보존합니다. `tools/reconstruction_inputs.py`가 이를 검증하며 `lift.py`는 상위 EXE 대신 이 입력만 사용합니다. 실행·native 재생성·assets·test·verify·build에 상위 원본 파일과 IDA DB가 필요하지 않습니다.

`npm run test:standalone`은 임시 폴더에 `web`을 복사하되 원본 EXE/IDA DB와 생성된 C·헤더·오브젝트·dist를 제외합니다. 원본 리소스 폴더나 EXE가 없는 상태에서 native → assets → test → verify → build를 모두 실행했고, 생성 WASM의 SHA-256은 작업 폴더와 같았습니다. 내장 리플레이 13/13 일치, 독립 dist 브라우저 게임 진입, WAV 16개/MIDI 재생 및 리소스 요청 105개(오류 0개)를 확인했습니다. 결과는 `test-results/standalone-report.json`, 명령별 로그와 `standalone-play.png`입니다. 임시 복사본은 검증 후 정리하며 원본은 삭제하지 않습니다.

독립 실행은 `web/run.bat`, 추가 원본 보존 감사는 `npm run verify -- --original-root ..`를 사용합니다. `web/public/assets`, `research`의 정적 분석/복원 입력, `native`의 플랫폼/수동 복원 코드와 `tools`는 보존해야 합니다. 보존된 `original-analysis.exe*`는 추가 분석 자료이며 재빌드 필수 입력이 아닙니다.
