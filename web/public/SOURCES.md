## 사용자가 제공한 한글판

이식 입력은 작업 폴더에 제공된 한글판입니다. 위키에 링크된 배포물과 바이트 단위로 같은 파일이라고 확인한 것은 아닙니다. 한글화 작성자, 개별 리소스 작성자, 저장된 플레이 기록 작성자와 별도 이용 허락은 확인되지 않았습니다. 이 자료를 새로 만든 원작 리소스라고 주장하지 않습니다.

- 분석 대상 `run.exe` SHA-256: `754034ee26fec593859607d2c2465d6a532589aabf15126d7b7f4bca28bdaf7a`.
- 원본 실행 파일과 리소스 100개의 경로·크기·SHA-256은 개발 트리 `web/research/original-manifest.json`에 보존합니다.
- 그중 리소스 99개는 `web/public/assets/`에 바이트 그대로 보존하며 `npm run verify`로 검사합니다. 브라우저의 새 기록은 이 내장 세이브를 덮어쓰지 않습니다.
- 초기 메모리 이미지와 코드 상수는 `web/research/initial-image.bin`, `web/research/reconstruction-inputs.json`에 출처 해시와 함께 보존합니다.
- 정적 분석 결과는 `web/research/0x*.c`, `.asm`이고, 변환 절차는 `web/tools/lift.py`, 플랫폼 연결 및 수동 복원은 `web/native/`입니다. 복원 코드는 원저자가 공개한 소스가 아닙니다.

## 웹 이식에서 추가한 부분

Phaser 기반 화면/프레임 연결, 브라우저 키보드·터치·게임패드 입력, Web Audio와 MIDI 합성, 브라우저 저장 및 가져오기/내보내기, 볼륨·음소거·일시정지/계속하기 UI와 반응형 배치를 추가했습니다. 원작의 BMP, MIDI, WAV 및 텍스트는 교체하지 않았습니다.

보존된 13개 리플레이는 원본 저장 점수와 저장 최대 콤보에 모두 일치합니다. 이는 모든 입력·음색·글꼴·화면이 원본 실행 환경과 완전히 같다는 보장은 아닙니다. 정적 분석 범위, 점수 불일치 수정 근거와 미검증 범위는 개발 트리의 `web/PORTING.md`에 기록했습니다.
